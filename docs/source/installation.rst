Installation
============

PyDMD requires Python 3 and the following dependencies: NumPy, SciPy, and Matplotlib.

Via pip
-------

The easiest way to install PyDMD is via pip:

.. code-block:: bash

    pip install pydmd

From source
-----------

To install the latest development version directly from GitHub:

.. code-block:: bash

    git clone https://github.com/PyDMD/PyDMD
    cd PyDMD
    pip install -e .
